# SW: Industry

**Minecraft 1.21.1 · NeoForge 21.1.234 · Java 21**
Мультиблочная промышленность для сборки **Sea Worthy**: первый огонь, глина и бронзовый век.

Печка тут — это не один блок. Это пятьдесят семь блоков, которые должны договориться быть
печью, пока ты их собираешь по силуэту, который рисуют тебе инженерные очки.

---

## Зависимости

| Мод | Зачем |
|---|---|
| [SW: Worldgen Core](../swgencore) | **обязателен** — океан, острова, бронзовая руда и `rock` для розжига |

Сборка и запуск сами подтягивают сиблинг (`runClient` копирует его jar в `run/mods`).

```bash
./gradlew build        # сборка + все автопроверки
./gradlew runClient    # клиент для разработки
```

## Геймплей

### 1. Первый огонь — примитивный костёр
Палки и брёвна в кучку. В одну руку **кремень**, в другую **камень** — бьём искру.
Шанс растёт с каждой попыткой: **15 % → 25 % → 50 % → 75 % → 100 %** на пятой.
Горит минуту, оставляет тлеющие угли: **1–5 угля и 1–3 сажи**. Дождь тушит.

### 2. Очки инженера — чертёж глазами
Палки + бумага + нитка (нитку дают три тростинки). Деревянная рамка, не броня.

> Надень очки рядом с поставленным **загрузочным отверстием** — вокруг проявится силуэт машины:
> полупрозрачные блоки там, где ставить кирпичи, красные коробки где должно быть пусто,
> голубые контуры недостающих стен. Шифт-ПКМ по отверстию — точный отчёт «сколько верно / что убрать».

Силуэт приходит пакетом с сервера: видишь ровно то, что сервер подтвердил.

### 3. Глиняная печь
**56 сырых кирпичей + загрузочное отверстие**, форма снята с референса один-в-один
(огневая камера 3×3, горловина, труба). Пока корпус сырой — жара не выше трети:
сушит глину и жарит рыбу. Но печь обжигает **саму себя**: каждый кирпич набирает своё время
от момента, когда попал в горячую машину (~3 минуты, у трубы дольше, в дождь — на четверть).
Последний кирпич щёлкнул — фанфары, порт темнеет, базовый потолок жара — 600 единиц
(60 % шкалы); дополнительная труба поднимает его максимум до 900. Печь получает **тир 1**.

### 4. Бронза
Бронзовую руду плавит только эта печь (`swindustry:kiln`, поле `tier`).
Инструменты и броня — между камнем и железом: копает как железо, служит меньше,
энчантится охотнее. Полный набор: меч, кирка, топор, лопата, мотыга, шлем–ботинки.

> Ванильные furnace, campfire и лодки отключены рецептами намеренно.

## Для пакмейкеров

**Конфиг** — `world/serverconfig/swindustry-server.toml`, синхронизируется на клиентов:
кулдаун удара, требование пары кремень+камень, время горения костра, тушение дождём,
базовое время готовки, множитель топлива.

**Датапаки переопределяют всё горячее:**

| Что | Где |
|---|---|
| Форма печи | `data/swindustry/structures/clay_kiln.nbt` (+ `/reload`) |
| Из чего строится корпус | тег `swindustry:kiln_wall` |
| Материалы тиров | теги `swindustry:kiln_wall_tier_1…N` |
| Чем высекают искру | `swindustry:fire_strikers/flint`, `…/stone` |
| Что обугливается | `swindustry:kiln_charrable` |
| Рецепты «только для печи» | тип `swindustry:kiln`: `ingredient/result/experience/cookingtime/tier` |

**Автоматизация:** на порту опубликован инвентарь — низ выгружает, верх принимает материал,
передняя грань ест всё, остальные стороны принимают топливо. Живое топливо наружу не уедет.

## Разработчику

Новая машина = одна структура `.nbt` + контроллер, наследующий `MultiblockControllerEntity`,
и стены-наследники `MultiblockPartBlock`. Каркас сам умеет поворот на четыре фасинга,
мгновенный распад при поломке (индекс владения), паузу на границе чанков
и вердикты для превью.

```java
MultiblockPattern pattern = StructurePatternLoader.builder()
    .fromResource(resources, SWIndustry.id("structures/my_machine"))
    .map(MyBlocks.WALL, BlockMatcher.tag(MyTags.WALL))
    .controller(MyBlocks.CONTROLLER)
    .build();
```

**Автопроверки** — `./gradlew check` гоняет шесть headless-тестов без запуска игры:
геометрия и ротации паттернов, лестница розжига, атлас GUI печи,
теги первого этапа, round-trip загрузчика структур, вода/дождь и температурные пороги печи.

**Отладка:** `/spawn_kiln` и `/spawn_cured_kiln` (права опа) или клавиша **F12** — ставит
готовую печь напротив игрока.
