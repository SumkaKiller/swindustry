================================================================================
          СТРУКТУРА И ВНЕШНИЙ ВИД ГЛИНЯНОЙ ПЕЧИ (CLAY KILN) В MINECRAFT
                            МОД: SW: INDUSTRY
================================================================================

Многоблочная глиняная печь (Размер структуры: 5x5x5 блоков).

Используемые блоки:
  [C] - Сырые глиняные кирпичи (swindustry:raw_clay_bricks / тег kiln_wall)
  [P] - Порт загрузки / контроллер печи (swindustry:clay_kiln_port)
  [_] - Внутренняя пустая камера / воздух (minecraft:air)
  [.] - Пустое пространство вокруг печи (minecraft:structure_void)


================================================================================
1. ПОСЛОЙНАЯ СХЕМА ПОСТРОЙКИ (ПО УРОВНЯМ Y = 0..4)
================================================================================

--- [ Y = 0: ПОЛ / ФУНДАМЕНТ ПЕЧИ ] ---
Сплошной пол из глиняных кирпичей 5х5 со срезанными углами (21 блок):

      .  C  C  C  .
      C  C  C  C  C
      C  C  C  C  C
      C  C  C  C  C
      .  C  C  C  .


--- [ Y = 1: НИЖНИЙ ЯРУС КАМЕРЫ + ПОРТ (ЛИЦЕВАЯ СТОРОНА) ] ---
Стенки по периметру, по центру спереди контроллер (P), внутри пустота 3х3:

      .  C  P  C  .  <-- Спереди (Front): порт загрузки [P] по центру
      C  _  _  _  C
      C  _  _  _  C  <-- Внутри: полость 3х3 для обжига
      C  _  _  _  C
      .  C  C  C  .


--- [ Y = 2: ВЕРХНИЙ ЯРУС КАМЕРЫ ] ---
Стенки топочной камеры высотой во второй блок, внутри пустота 3х3:

      .  C  C  C  .
      C  _  _  _  C
      C  _  _  _  C  <-- Полость 3х3 продолжается вверх
      C  _  _  _  C
      .  C  C  C  .


--- [ Y = 3: СВОД / КУПОЛ ПЕЧИ ] ---
Сужение до кольца 3х3 с отверстием по центру для выхода газов:

      .  .  .  .  .
      .  C  C  C  .
      .  C  _  C  .  <-- Центральное отверстие тяги
      .  C  C  C  .
      .  .  .  .  .


--- [ Y = 4: ДЫМОХОД / ТРУБА (FLUE) ] ---
Крестообразная труба дымохода (может наращиваться выше для лучшей тяги):

      .  .  .  .  .
      .  .  C  .  .
      .  C  _  C  .  <-- Выходное сопло дымохода
      .  .  C  .  .
      .  .  .  .  .


================================================================================
2. ОБЩИЙ 3D/ИЗОМЕТРИЧЕСКИЙ ВИД СНАРУЖИ
================================================================================

                     [ ДЫМОХОД ]
                       +-----+
                       |  C  |           <-- Y=4 (Труба 3х3 крестом)
                 +-----+     +-----+
                 |  C  | (_) |  C  |
                 +-----+     +-----+
                       |  C  |
                    +--+-----+--+
                 .-'             '-.
               .'   +-----------+   '.   <-- Y=3 (Сужающийся купол)
             .'     | C   C   C |     '.
           .'   +---+-----------+---+   '.
          /     | C |           | C |     \
         /      +---+           +---+      \
        |       | C |           | C |       | <-- Y=2 (Верхний пояс стен)
        |       +---+-----------+---+       |
        |       | C | [  (P)  ] | C |       | <-- Y=1 (Лицевой порт [P])
        |       +---+-----------+---+       |
        |       | C |     C     | C |       | <-- Y=0 (Сплошной кирпичный под)
        '-------+---+-----------+---+-------'
               \_____________________________/


================================================================================
3. ДЕТАЛИ И ОСОБЕННОСТИ МОДЕЛИ
================================================================================
* Текстура блоков:
  - Стены: raw_clay_bricks (серые/бежевые сырые глиняные кирпичи с бороздками).
  - Порт (clay_kiln_port):
    - В выключенном состоянии: тёмное арочное окошко топки с железной/глиняной заслонкой.
    - В активном состоянии (lit): ярко светящееся жерло с горящими внутри дровами и углями.
* Дымоход:
  - Труба над куполом выводит дым и частицы искр во время работы печи.
